# Demos

Versiones anteriores de la app que no necesitan Firebase:

- `demo-3-vistas.html`: ábrelo con doble clic. Tiene un selector de 3 usuarios (Admin, Organizador, Jugadora), guarda los datos en el navegador (localStorage) y usa Google Maps si pegas una API key u OpenStreetMap si no.
- `prototipo-mapa-ilustrativo.html`: el primer prototipo, con un mapa dibujado. Fuera de claude.ai funciona en modo demo.
